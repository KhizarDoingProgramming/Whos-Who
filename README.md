# Who's Who | Animation & Creative Studio

![Header Image Placeholder](https://images.unsplash.com/photo-1550684848-fac1c5b4e853?q=80&w=1200)

## 🎥 Overview

**Who's Who** is a premium, high-impact creative portfolio website inspired by the artistic and edgy aesthetic of [Blink My Brain](https://blinkmybrain.wtf). Designed for motion directors, animators, and creative studios, it features a gritty "street-art" vibe combined with modern, sophisticated web interactions.

The project is a multi-page experience built with pure **Vanilla HTML5, CSS3, and JavaScript**, ensuring maximum performance and a unique visual identity that avoids generic template looks.

---

## ✨ Key Features

- **High-End Aesthetics**: A custom-designed light-grey and metallic gold theme with a subtle film grain texture.
- **Dynamic Masonry Portfolio**: A responsive, multi-category gallery with over 40+ project placeholders.
- **Micro-Animations**: Smooth, scroll-triggered reveal animations and interactive hover states.
- **Multi-Page Architecture**: Dedicated pages for:
  - **Gallery**: A comprehensive look at the studio's full portfolio.
  - **About**: A split-screen narrative of the studio's philosophy and vision.
  - **Memories**: An artistic "memory wall" of studio life and inspirations.
  - **Contact**: A professional, multi-column contact suite with a styled form.
  - **Shop**: A minimalist storefront for creative assets and limited edition prints.
- **Performance Optimized**: No heavy frameworks—just clean, optimized code for lightning-fast load times.
- **SEO Ready**: Semantic HTML structure with proper meta tags for search engine visibility.

---

## 🛠️ Tech Stack

- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Custom Design System, Flexbox, CSS Grid)
- **Interactivity**: Vanilla JavaScript (Intersection Observer API for animations)
- **Assets**: High-quality curated imagery from Unsplash
- **Fonts**: Google Fonts (Archivo Black, Inter, Permanent Marker)

## 🚀 Installation & Usage

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/whos-who-studio.git
   ```
2. **Navigate to the Directory**:
   ```bash
   cd whos-who-studio
   ```
3. **Open the Project**:
   Simply open `index.html` in your favorite browser.
